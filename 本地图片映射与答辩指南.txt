【一】后端本地图片给前端显示（已落地方案）

1) 后端放图
- 将图片统一放到：F:\Python-program\111\static\...
- 示例：F:\Python-program\111\static\birds\egret.jpg

2) 后端静态目录映射
- backend/main.py 已挂载：/static -> F:\Python-program\111\static
- 访问示例：http://<PC_LAN_IP>:8000/static/birds/egret.jpg

3) 数据库存储规范（重点）
- 推荐在 bird.image_url 中存相对 URL：/static/birds/egret.jpg
- 不要存本地磁盘路径（例如 F:\xxx\egret.jpg）

4) 后端兼容性处理（本次实现）
- 新增 image_url 归一化逻辑：
  - http/https/data:image 直通
  - Windows 路径中的 \ 统一为 /
  - 若包含 /static/ 段，自动截取为 /static/... 返回
  - 空值或无效本地盘符路径，回退占位图
- 已应用到：
  - /api/recommend
  - /api/bird
  - /api/bird/{bird_id}

5) 前端拼接策略
- UniApp 使用 getBaseUrl() + image_url 方式拼接相对路径
- 非 http 的 image_url 会自动拼接后端 baseURL

6) 联调关键点
- 手机与电脑必须同一 Wi-Fi
- 后端使用 0.0.0.0:8000 启动
- 前端 baseURL 必须配置为电脑局域网 IP（不能是 localhost）
- 可通过 /api/meta 查看当前服务 base_url
